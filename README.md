# Supplementary bibliographic data accompanying the review “Eco-Driving Meets Intelligence: Reinforcement Learning for Efficient Driving.

# Dataset
The current workbook is RL-EcoDriving-1991-2026-Dataset.xlsx.
Search window: 1991–2026.
Search last updated: 16 August 2026; coverage of 2026 is partial.
Bibliographic trend corpus: 2,649 records.
The bibliographic corpus includes broader eco-driving literature and should not be interpreted as 2,649 eligible RL-based studies.

# Interpretation
Metadata matches describe terms found in bibliographic records. They do not, by themselves, verify a study’s safety mechanisms, validation level, statistical practices, or reproducibility.
